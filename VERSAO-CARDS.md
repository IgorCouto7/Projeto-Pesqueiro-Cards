# Comparar as apresentações do caixa completo

- Abra http://127.0.0.1:8000/cards para usar os cards no centro da aba Comandas.
- Abra http://127.0.0.1:8000/classico para usar a lista lateral da versão original.
- A abertura de comanda é pelo nome da pessoa ou grupo, no botão Nova comanda.
- Clique no card para abrir a janela de consumo. Selecione um produto do cadastro e informe a quantidade, sem digitar o preço.
- As abas Produtos e estoque e Caixa e histórico permanecem iguais.
- Os lançamentos, o estoque e os pagamentos ficam no mesmo banco do caixa.
- O projeto original no GitHub não é alterado pela versão com cards.

A versão simplificada anterior está preservada na branch backup/prototipo-cards.
Não copie o banco pesqueiro.db do protótipo para caixa.sqlite3: são formatos diferentes.
